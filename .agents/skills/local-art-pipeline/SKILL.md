# 本地美术管线关联

游戏项目的美术生产环境是 `D:/AiDraw`。本技能只提供关联和游戏侧约束；外部技能、配置、脚本和工作流以该目录的当前文件为准，不在游戏仓库复制维护。

## 读取入口

1. 先读 [AiDraw 开发约定](D:/AiDraw/AGENTS.md)，确认外部目录可访问。
2. 制定卡牌需求、提示词、系列风格或验收素材时，读 [card-game-art](D:/AiDraw/.agents/skills/card-game-art/SKILL.md)。
3. 实际生成、重绘图片或调整工作流时，再读 [comfyui-draw](D:/AiDraw/.agents/skills/comfyui-draw/SKILL.md) 及其引用的 API 文档。相关引用中的相对路径均相对于外部技能所在目录解析。
4. 出图前读取 [ComfyUI 配置](D:/AiDraw/config/comfyui.json) 和选用的工作流。启动与接口操作按外部技能执行，命令工作目录明确设为 `D:/AiDraw`，不能把游戏项目根目录当作绘图项目根目录。

外部技能不在本会话技能列表中时，直接读取上述绝对路径即可；不必安装副本。路径失效时报告缺少的入口，不自动下载模型、重装环境或改用云端绘图。

## 本游戏的输入与选择标准

- 卡牌配置源为游戏仓库 `GameData/Excel/Cards.xlsx`：第 1 行字段名、第 2 行类型、第 3 行起数据。用卡牌 Id 关联美术，不用可翻译名称作为资源标识。
- 原始项目需求为战士、猎人卡牌，每张 20 个候选，选择系列风格统一的资源。该数量用于执行既有整批生产任务；用户另行指定单卡或样图数量时以本次请求为准。仅配置技能关联不启动生成任务。
- 已有画风目标：参考《杀戮尖塔》的卡牌阅读性，更写实的形体和材质，加入《极乐迪斯科》式表现性油画笔触与情绪色彩；制作原创主体和构图。实际已有规格和用户后续修改优先。
- 插画与标题、规则、费用、边框分离；文字由游戏 UI 和本地化系统渲染。导出尺寸、横竖比例、裁切安全区先核对实际卡面或已确认规格，不直接套用外部技能的竖图默认尺寸。
- 游戏中旧 `Tools/Art/prepare_prompts.py` / `ArtProduction` 记录仅是已有需求线索，不是本地 ComfyUI 执行入口。旧脚本按单表头读取 Excel，并将候选路径写到游戏目录；使用前须适配当前两行表头和外部输出目录，不直接运行旧脚本推进生产。

## 生产、验收与 Git 边界

复用外部技能的服务识别、队列检查、执行记录与视觉验收流程。批量任务按卡牌 Id、候选编号和 seed 记录；记录实际工作流、模型、提示词、输出路径及筛选结果。提交 prompt_id、任务完成、视觉验收是不同状态，不能互相代替。

模型、ComfyUI 程序、环境、工作流、参考图、候选原图、日志与运行记录均保留在 `D:/AiDraw` 的配置指定目录。建议用 `MobileSlayTheSpire` 项目子目录隔离生产记录和输出；实际文件归档规则遵循外部技能及配置。

本游戏仓库只管理此关联技能和必要的游戏侧入口说明。不要把 `D:/AiDraw` 加成子模块、目录联接或符号链接，不复制管线代码/模型/环境，不在本游戏 Git 中提交外部生产目录，也不替外部仓库执行提交。

用户要求将选中的成品接入游戏时，才把最终运行时资源导入游戏 Assets，并记录来源；候选和本地生产环境仍保留在外部。该阶段遵循游戏已有资源导入与 Git LFS 规则，涉及 LFS 上传排查时读取本项目 project-lfs 技能。当前仅建立关联不导入图片。
