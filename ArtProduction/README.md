# 卡牌美术生产

当前状态：**尚未生成图片，尚未完成风格筛选**。当前会话没有 image_gen 工具，不能将提示词清单计为已完成美术。

`jobs.jsonl` 是正式卡表对应的 320 项生产任务：16 张卡，每张 20 个独立样例。由 `Tools/Art/prepare_prompts.py` 生成；仅准备提示词，不连接 API、不产生费用。

目标是原创暗黑幻想卡牌：半写实人体和磨损材质，表现主义油画笔触、粗画布、心理性的忧郁气氛，炭黑／脏象牙白／赭石／氧化青统一调色。战士辅色锈红，猎人辅色苔绿。借鉴用户所述游戏的可读性和油画表现力，不复制其角色、构图或卡面。

每张卡的 20 个样例使用 5 种构图 × 4 种光照变化，保持同一套材质与笔触。输出为 3:2 横向插画、不含文字／边框，四周留 8% 安全区。正式生成时先用一张战士卡和一张猎人卡建立风格锚点，再以选中参考约束其余批次。

筛选流程：

1. 确认每个 card_id 下真实存在 20 张独立生成图，保留原始提示词及可用的模型／种子记录。
2. 排除肢体或武器错误、动作不匹配、文字水印、构图裁切问题。
3. 用缩略图对比主题识别度、明暗层级、笔触、材质、饱和度，优先全套一致性。
4. 每卡选 1 张，记录候选编号与理由；未达标就补画，不能用重复图补足数量。
5. 最终图放入 `Assets/Resources/CardArt/<card_id>.png`，在游戏实机确认小尺寸可读性，再通过 LFS 提交资源。

当前界面为纯文字功能原型；正式插画接入及最终美术 UI 仍待图片生产完成。不要把 `pending_generation` 改成完成，除非对应图片已经生成和检查。
